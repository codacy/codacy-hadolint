## Do not copy an entire filesystem from another stage

### Problematic code:

Copying an entire previous build stage:

```dockerfile
FROM someimage:tag as build
[...]
FROM otherimage:tag
COPY --from=build / /
```

Or copying an entire image:

```dockerfile
COPY --from=foo-image:bar / /
```

### Correct code:

Just continue using the stage, if the entire filesystem is desired:

```dockerfile
FROM someimage:tag
[...]
```

Or copy only the needed paths:

```dockerfile
COPY --from=foo-image:bar /specific/path /
```

### Rationale:

Copying an entire image filesystem is inefficient as it likely drags in much more files than needed, which needlessly increases image size.
This may also force a new image layer to be created instead of reusing existing layers.
Additionally some bits from the original image may be missing for correct function, e.g. `USER` or `ENTRYPOINT` directives.
