## MAINTAINER is deprecated

### Problematic code:

```dockerfile
FROM busybox
MAINTAINER Lukas Martinelli <me@lukasmartinelli.ch>
```

### Correct code:

```dockerfile
FROM busybox
LABEL maintainer="Lukas Martinelli <me@lukasmartinelli.ch>"
```

Better yet, adhere to the predefined [OCI labels keys](https://github.com/opencontainers/image-spec/blob/main/annotations.md#pre-defined-annotation-keys):
```dockerfile
LABEL org.opencontainers.image.authors="Lukas Martinelli <me@lukasmartinelli.ch>"
```

### Rationale:

`MAINTAINER` is deprecated since Docker 1.13.0: https://docs.docker.com/engine/deprecated/#maintainer-in-dockerfile
