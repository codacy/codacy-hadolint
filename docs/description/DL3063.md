## Stage name should not be a reserved word

### Problematic code:

```dockerfile
FROM debian:bullseye AS scratch
```

### Correct code:

```dockerfile
FROM debian:bullseye AS foobar
```

### Rationale:

`scratch` and `context` are reserved words and should not be used as stage names.
See also: https://docs.docker.com/reference/build-checks/reserved-stage-name/
